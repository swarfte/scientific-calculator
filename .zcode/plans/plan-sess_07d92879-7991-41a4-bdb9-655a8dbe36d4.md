## 新增/填寫檔案

1. **`lib/features/calculator/model/expression/sequence_role.dart`** (新增)
   - Enum：`functionArgument, groupContent, fractionNumerator, fractionDenominator, rootRadicand, rootDegree, powerBase, powerExponent`。

2. **`lib/features/calculator/model/expression/tree_expression_document.dart`** (新增)
   - 欄位：`root: SequenceNode`、`cursor: CursorPosition`（不保存 derived string）。
   - `copyWith`、`factory empty()`（root = 空 Sequence，cursor 在 root 結尾）。

3. **`lib/features/calculator/model/expression/tree_index.dart`** (新增)
   - 由 `root` 單次 DFS 建立 index：
     - `findSequence(NodeId)`、`findNode(NodeId)`、`rootId`
     - `findParentOfSequence(NodeId)` → `SequenceLocation? {ownerNode, ownerIndex, parentSequence, role}`
     - `findParentOfNode(NodeId)` → `NodeLocation? {parentSequence, index}`
     - `isValidCursor`、`clampCursor`（無效 sequenceId → root end，越界 → clamp）。
   - 同時記錄每個 composite node 的 child sequences 與 role，供 navigator 使用。

4. **`lib/features/calculator/service/expression_navigator.dart`** (填寫現有空檔)
   - `ExpressionNavigator`：`moveLeft/moveRight/moveUp/moveDown`，input/output 為 `TreeExpressionDocument`（只改 cursor，不改 Tree）。
   - 內部每次呼叫建立 `TreeIndex`。
   - **Cursor 慣例（明確化）**：
     - `textOffset == null`（gap mode）：`nodeOffset ∈ [0,len]` 表示在 `children[nodeOffset]` 前的間隙。
     - `textOffset != null`（text mode）：cursor 在 NumberNode `children[nodeOffset]` 內，char `textOffset ∈ [0, value.length]`。
   - Left/Right：數字字元移動 → 離開 node → 進入相鄰 composite（左入=後方 child 末端；右入=前方 child 開頭）→ child sequence 邊界離開 owner。
   - Up/Down：fraction denominator↔numerator、power base↔exponent、root radicand↔degree，保留並 clamp `nodeOffset`/`textOffset`；其餘不動。
   - 無效 cursor 安全回復（root end 或 clamp）。

5. **測試**（建立第一個 `test/` 目錄）
   - `test/features/calculator/service/expression_navigator_test.dart`：覆蓋計劃全部案例（`1|23`→`12|3`、`sin(30|)`→`sin(30)|`、`sin(|30)`→離開函數、分子↔分母左右、上下水平保留、exponent↔base、root 邊界、無效 cursor 回復）。
   - `test/features/calculator/model/expression/tree_index_test.dart`：`findSequence/findNode/parent relationship` sanity。

## Cursor 慣例（實作時會寫入文件註解）
- Gap mode (`textOffset == null`)：`nodeOffset` 為 children 前的間隙位置，`0`=開頭、`len`=結尾。
- Text mode (`textOffset != null`)：cursor 在 `children[nodeOffset]`（必為 NumberNode）內。
