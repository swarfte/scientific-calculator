## 新增檔案

1. **`lib/.../model/expression/edit_result.dart`** (新增, 輕量)
   - Value type：`EditResult({document, message})`。雖然 editor 方法直接回傳 document（已確認），但仍建立此型別供 Phase 6 ViewModel 提示用途，並在 editor 內部作為 helper 使用。

2. **`lib/.../service/tree_rewriter.dart`** (新增)
   - Immutable Tree 更新的三個基本操作，沿 parent path 向上重建：
     - `replaceSequence(root, sequenceId, replacement)` — 用 `TreeIndex.findParentOfSequence` 取得 owner chain，逐層 `copyWith` 重建（保留所有未動 node 的 ID）。
     - `replaceNode(root, nodeId, replacement)` — 取代 parent sequence 中的 child。
     - `removeNode(root, nodeId)` — 從 parent sequence 移除 child。
   - 由 `TreeIndex` 提供 owner/parent 資訊；每個 composite node 的 `copyWith` 已保留 ID（Phase 1 invariant），因此深層修改後其他 node ID 不變。

3. **`lib/.../service/tree_expression_editor.dart`** (新增)
   - `TreeExpressionEditor`，13 個方法（對應計劃 API），每個 input/output 為 `TreeExpressionDocument`（immutable，只回傳 document）。
   - 內部每次呼叫建立 `TreeIndex` + 委派 `TreeRewriter`。
   - **行為規格（依計劃）**：
     - **數字**：text mode 在 textOffset 插入；gap mode 追加至左方 NumberNode 末端／前插至右方 NumberNode 開頭／否則新建 NumberNode；連續輸入合併。
     - **小數點**：同一 NumberNode 最多一個 `.`；空位置建 `0.`。
     - **運算符（已確認 MVP 規則）**：空 root 只允許 unary subtract；連續 operator 替換前一個（`*` 或 `/` 後接 `-` 例外保留）；cursor 落在 operator 後方。
     - **常數**：插入 ConstantNode（pi/e/Ans）。
     - **函數**：插入 FunctionNode（空 argument），cursor 進入 argument 開頭。
     - **分數**：空位置建空 FractionNode，cursor 進 numerator；左方 NumberNode 提升為 numerator，cursor 進 denominator。
     - **根號**：square root / nth root 建 RootNode，cursor 進 radicand。
     - **指數**：`x^y` 提升左方 NumberNode 為 base，空 exponent + cursor；`x^2` 建 exponent `2`，cursor 移到 PowerNode 後方。
     - **群組**：建 GroupNode（空 content），cursor 進 content 開頭。
     - **Backspace（8 條優先規則）**：NumberNode 內刪字元 → 清空移除 NumberNode → gap 前方簡單 node 移除 → 空 child sequence 開頭 unwrap/remove owner（fraction/function/root/power 各有降級或移除行為）。
     - **clear**：回傳空 document。
