# 計算機按鍵功能實現計劃

## 範圍概覽

為 `calculator_keypad.dart` 中標記 `// need to implement` 的按鍵補完功能,並改造按鍵圖標支援真正的 2D 排版(上下標、帶分數)。涉及 **3 個新 node 類型**、**1 個既有 node 補方法**、**6 個新 ViewModel 方法**、**CalculatorKey Widget label 改造**,並貫穿 10 個 service/model 檔案。

---

## 一、新增 3 個 ExpressionNode

每個 node 仿照現有 `FractionNode`/`PowerNode`/`RootNode` 的模式(immutable + `copyWith` + factory)。

### 1. `LogarithmNode` (lib/.../node/logarithm_node.dart) — 供 log_xy、log₂
- 欄位:`base` (SequenceNode), `argument` (SequenceNode)
- factory:`empty()`(兩者皆空)、`withDefaultBase(int base)`(base 預填 NumberNode,argument 空)
- 數學:`log_base(argument)`

### 2. `MixedFractionNode` (lib/.../node/mixed_fraction_node.dart) — 供 a b/c 帶分數
- 欄位:`whole` (SequenceNode), `numerator`, `denominator`
- factory:`empty()`(三者皆空)
- 數學:`whole + numerator/denominator`

### 3. `ScientificNode` (lib/.../node/scientific_node.dart) — 供 Exp
- 欄位:`mantissa` (SequenceNode), `exponent` (SequenceNode)
- factory:`empty()`
- 數學:`mantissa × 10^exponent`

## 二、貫穿式整合(每個新 node 都要動這些檔案)

| 檔案 | 改動 |
|------|------|
| `sequence_role.dart` | 加 `logBase, logArgument, mixedWhole, mixedNumerator, mixedDenominator, scientificMantissa, scientificExponent` |
| `tree_index.dart` → `childSequencesOf` | 3 個新 case,回傳對應 (sequence, role) |
| `tree_rewriter.dart` → `_withSequence` | 3 個新 case,依 role 替換 child sequence |
| `tree_expression_tex_serializer.dart` | 加 `_serializeLogarithm/MixedFraction/Scientific` + `default` case |
| `expression_compiler.dart` → `_compileNode` | 加 3 個 case;compile 邏輯見下 |
| `expression_validator.dart` → `_validateSequence` | 加 3 個 case,驗證各 child sequence 非空 |
| `expression_navigator.dart` → `_moveVertical` | 加 role 對(base↔argument、whole/numer↔denom、mantissa↔exponent) |
| `exact_value_evaluator.dart` → `_compileNode` | 加 3 個 case(見下) |

### 編譯邏輯(decimal 路徑)
- `LogarithmNode` → `Divide(Ln(argument), Ln(base))`
- `MixedFractionNode` → `Plus(parseSequence(whole), Divide(numerator, denominator))`
- `ScientificNode` → `Times(parseSequence(mantissa), Power(Number(10), parseSequence(exponent)))`

### 精確求值(exact 路徑)
- `LogarithmNode` → `null`(對數非代數精確,fallback decimal)
- `MixedFractionNode` → `whole + numerator.divide(denominator)`
- `ScientificNode` → mantissa × 10^exponent(整數 exponent 時,否則 null)

### TeX 顯示
- `LogarithmNode` → `\log_{base}{argument}`
- `MixedFractionNode` → `whole\frac{numerator}{denominator}`
- `ScientificNode` → `{mantissa} \times 10^{exponent}`(自然顯示區採數學排版;Exp 語義為 mantissa×10^exp,計算結果如 1E4=10000)

## 三、Editor 補方法 (tree_expression_editor.dart)

仿照 `insertFraction`/`insertPower`/`insertSquare` 的「左方 NumberNode 提升為槽位」模式:
- `insertLogarithm(document)` — 空位置建空 LogarithmNode,游標進 argument;左方有 NumberNode 則提升為 argument,游標進 base
- `insertLogarithmBase2(document)` — 建 `withDefaultBase(2)`,游標進 argument
- `insertMixedFraction(document)` — 建空 MixedFractionNode,游標進 whole;左方有 NumberNode 提升為 whole,游標進 numerator
- `insertScientific(document)` — 左方有 NumberNode 提升為 mantissa,建空 exponent,游標進 exponent;否則建空 mantissa

並在 `backspace` 的 `_backspaceAtSequenceStart` 為新 node 加降級規則(仿現有 PowerNode/FractionNode):
- ScientificNode exponent 空 → 解除保留 mantissa
- MixedFractionNode denominator 空 → 退到 numerator;numerator 空 → 退到 whole
- LogarithmNode argument 空 → 移除整個 node

## 四、CalculatorKey Widget label 改造 (calculator_key.dart)

加可選 `Widget? labelWidget` 參數,build 時優先使用:
```dart
child: Center(child: labelWidget ?? Text(label, ...))
```
向後相容:既有 String label 全部保留。Keypad 加 `_widgetKey` helper 接受 Widget label。

## 五、Keypad 改造 (calculator_keypad.dart)

修正錯誤接線 + 新增 callback + Widget 圖標:

| 按鍵 | 現況 | 改為 |
|------|------|------|
| sin⁻¹ / cos⁻¹ / tan⁻¹ | 錯接 onSin/onCos/onTan | 新增 `onArcSin/onArcCos/onArcTan`;Widget label(`sin` + 上標 `⁻¹`) |
